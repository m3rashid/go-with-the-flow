# Go with the Flow

Event-driven HTTP server in pure Go. Crazy fast. Entirely configurable with custom flows.

## Tech

Go · Fiber · MongoDB · JWT · V8 (rogchap/v8go)

## Features

- Event-driven architecture
- Custom flow definitions executed on triggers
- High throughput, low latency
- JWT auth, validation, env-based config

## Quick start

```bash
git clone https://github.com/m3rashid/go-with-the-flow.git
cd go-with-the-flow
cp .env.example .env   # fill values
go run main.go
```
